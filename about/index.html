你好，我是木之风。

正在把学习，变成一件长久的事。

这里是 Hickercf'blog，一本持续更新的个人笔记本。

我在这里记录渗透学习、AI 探索、课程笔记与生活碎片。它不限定在某个固定方向，而是跟着每一次好奇、练习与实践，慢慢留下自己的学习轨迹。

我在这里写些什么

  • 渗透学习：从网络基础到 SQL 注入、工具使用与实验复现，整理原理和实践心得。
  • AI 学习：从 Python 基础到大语言模型，记录探索与理解。
  • 课程笔记：整理操作系统、数据库、编译原理与汇编语言。
  • 生活随笔：在代码与书本之外，收藏日常里的想法。

保持好奇，持续记录

比起把内容包装得很宏大，我更希望这里能留下真实的学习过程。看懂了什么、还在思考什么，都值得写下来。

如果这些笔记恰好对你有帮助，很高兴我们在这里相遇。
