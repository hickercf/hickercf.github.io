漏洞技术原理深析 (MS17-010)

MS17-010（CVE-2017-0144）是 Windows SMBv1 协议实现中的经典缓冲区溢出漏洞：

  1. 协议缺陷定位
    • 漏洞位于 Windows 内核驱动 srv.sys。
    • 该驱动负责解析并处理 SMBv1 协议的报文请求。
  2. 数学与逻辑错误（整型越界与缓冲区溢出）
    • 当客户端向服务器发送扩展属性（Extended Attributes, FEA）请求时，会调用 SrvOs2FeaListToNt 函数将 OS/2 FEA 格式转换为 NT FEA 格式。
    • 在计算所需缓冲区大小时，系统对数据长度的处理存在逻辑缺陷：当输入的 FEA 列表长度超出预期（即 FeaListSize 发生整型回绕或计算溢出）时，分配给转换后数据的内核池缓冲区偏小。
    • 随后系统在执行数据复制时，超长的数据覆盖了相邻的内核池内存结构，从而造成内核池溢出（Pool Overflow）。
  3. 安全危害
    • 攻击者构造特定格式的畸形 SMB 请求，无需经过身份认证即可破坏内核数据结构并劫持控制流，直接以操作系统的最高权限（SYSTEM 权限）执行代码。

靶机加固与防御配置方案

针对该实验中的第 5 部分防御要求，可以从协议禁用、系统补丁及边界防护三个维度实施加固：

  1. 彻底禁用过时的 SMBv1 协议
    GUI 方式：打开“控制面板” -> “程序和功能” -> “启用或关闭 Windows 功能”，找到并取消勾选 SMB 1.0/CIFS 文件共享支持，保存后重启系统。
  2. 安装安全更新补丁
    • 检查系统补丁列表，确认已安装针对 MS17-010 的安全补丁：
      • Windows 7 / Server 2008 R2 对应补丁号通常为 KB4012212 或 KB4012215。
    • 可在命令行运行以下命令检查是否已修复：DOS

wmic qfe get hotfixid | findstr 4012212
```
3. 网络与防火墙策略
- 在网络边界设备及主机防火墙上阻断敏感端口入站流量：
- 禁用 TCP 139、445 端口对不可信网络的开放。
- 仅允许内网受信任的网段或管理主机访问必要的文件共享服务。
