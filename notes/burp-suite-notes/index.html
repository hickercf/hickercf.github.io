BP 是干什么的？

BP 是一个用于 Web 安全测试的代理工具，可以拦截并修改浏览器和服务器之间的 HTTP/HTTPS 通信。
正常访问：

BP 的核心模块：

Proxy 代理

作用：拦截浏览器请求。

HTTP History

作用：可以查看所有经过 Burp 的请求。
例如：

GET /index
GET /login
POST /api/login
GET /user?id=1001

Repeater

这个非常重要，中文名：请求重放器。
流程：
当你抓到一个请求：

GET /product?id=5

发送到Repeater，然后修改为：

GET /product?id=6

然后点击：Send，看服务器的返回。

Intruder

作用：自动化测试
例如你有 id = 1，你想测试 id = 1 ~ 1000，可以使用 Intruder

Decoder

编码转化器，通常用于转换 Base64、URL 编码、Hex等

Comparer

作用：比较两个响应的差异
