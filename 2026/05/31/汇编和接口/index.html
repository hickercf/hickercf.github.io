寄存器：

以8086为例：

寄存器都是16位

通用寄存器 AX, BX, CX, DX
每个寄存器又可以分为高8位和低8位：如AX -> AH, AL 每个寄存器都可以独立使用

处理数据的尺寸
字节 byte 8位 字 word 16位

简单的汇编指令：
mov ax bx ax <- bx
add ax bx ax <- ax + bx
jmp 3:0b16 CS <- 3h IP <- 0b16h
jmp ax ip <- ax

16位cpu:
1.运算器一次最多处理16位数据
2.寄存器最大宽度位16
3.reg和alu之间的数据通路为16位

地址：(内存中没有段的划分)
20位物理地址 16位段地址 16位偏移地址 -> 一个段的最大长度为 2 << 16 = 64kb
20位地址只在内存中使用
物理地址 = 段地址 << 4 + 偏移地址

段寄存器：
CS DS SS ES (段：segment)

CS和IP：
CS 代码段寄存器 IP 指令指针寄存器
读取一个指令后IP自动增加一个指令的长度
启动，复位后 CS = FFFFH IP= 0000H

代码段：
最大64kb, 起始地址16倍数

call

CPU执行call操作的时候进行两步操作：
1.将当前的CS和IP压栈，或者只压栈当前的IP
2.转移

  • 第一种情况：call标号
    相当于：
    push IP
    jmp near ptr 标号

  • 第二种情况：call far ptr 标号
    相当于：
    push CS push IP jmp far ptr 标号`

  • 第三种情况：call 16位reg
    相当于：
    push IP
    jmp 16位reg

  • 第四种情况：call word ptr 内存单元地址

    相当于：

    push IP
    jmp word ptr 内存单元地址
    如果是dword的话
    call dword ptr 内存单元地址
    相当于：
    push CS
    push IP
    jmp dword ptr 内存单元地址

标志寄存器Related

  1. ZF寄存器：判断相关指令结果是否为0，是0则ZF = 1

  2. PF寄存器：奇偶标准位，记录相关指令执行后结果的所以bit中1的个数是否为偶数，如果是偶数则PF = 1，16位寄存器进行操作时，只看低8位。

  3. SF寄存器，记录相关指令执行后结果是否位负，如果为负则SF = 1

  4. CF寄存器，在进行无符号数运算的时候，记录运算结果最高有效位向更高位的进位值

  5. OF寄存器，在进行有符号数的运算的时候，如果结果超过机器表示范围，称为溢出

  6. DF寄存器和串传送指令：
    df是方向标志位，在传处理指令中控制si, di的增减

    1. movsb

      相当于执行下面几步操作
      es:[di] = ds:[si]
      if df = 0:

      `(si) = (si) + 1`
`(di) = (di) + 1`

      if df = 1:

      `(si) = (si) - 1`
`(di) = (di) - 1`

      使用格式为：rep movsb
      相当于：
      s:movsb
      loop s
      所以使用这个指令的时候要设置cx, si, di, es, ds

      1. movsw

        具体操作与movsb相同，si, di的步长改为2

      2. df的设置指令：

        cld: df <- 0
        sld: df <- 1

内中断

当cpu发生以下情况时，将产生中断信息

  1. 除法错误，如div的指令溢出 –中断码0
  2. 单步执行 –中断码1
  3. 执行into 指令 –中断码4
  4. 执行int指令 –中断码为指令参数

中断向量表：

储存在内存的0000:0000 到 0000:03FF 这1024个单元中

中断过程(8086CPU)：

  • 从中断信息中获取中断类型码

  • 标志寄存器入栈(中断过程要改变标志寄存器的值)

  • 设置标志寄存器第八位的TF和第九位IF的值为0

  • CS入栈

  • IP入栈

  • 从内存地址为中断类型码 * 4 和中断类型码* 4 + 2 两个字单元中读取中断处理程序的入口地址，设置CS和IP
    相当于：

    1. 获取终端类型码N
    2. pushf
    3. TF = 0, IF = 0
    4. push CS
    5. push IP
    6 (IP) = (N * 4), (CS) = (N * 4 + 2)

  • 中端处理程序和iret 指令

    iret 指令相当于：

      `pop IP`
  `pop CS`
  `popf`

CPU可以直接读三个地方的数据：

端口的读写

CPU通过端口地址来定位端口。端口所在的芯片与CPU通过总线相连，端口地址和内存地址一样，通过地址总线来传送。PC系统中，CPU最多可以定位64KB个不同的端口，则端口的地址范围为0-65535

端口的读写指令只有两条

in 和 out

访问端口：

in al, 60h 从60h端口读入一个字节

  • CPU通过地址线将地址信息60h发出；

  • CPU通过控制线发出端口读命令，选中端口所在芯片并且告诉他要读

  • 端口所在的芯片将60h端口的数据通过数据线送入CPU

in 和 out 指令只能al 或者 ax寄存器存放从端口得到的数据或者要发给端口的数据

CMOS RAM芯片

PC机中，有一个CMOS RAM芯片，特征如下：

  • 包含一个实时钟和一个有128个储存单元的RAM存储器

  • 芯片靠电池供电，关机信息不丢失

  • 128个字节中，实时种占用0-0dh单元保存时间信息，其余大部分单元用于保存系统配置信息，供系统启动时BIOS程序读取

  • 芯片内部有两个端口，70h和71h来读写CMOS RAM

  • 70h为地址端口，存放要访问CMOS RAM单元的地址数据；71h为数据端口，存放从CMOS RAM中要读或者要写的数据。

外中断信息

现在我们知道，外设的输入被存放在端口中，可是外设的输入随时有可能到达，CPU如何及时地知道，并且进行处理呢？

CPU提供中断机制来满足这些要求。与内中断不同，还有一种中断信息，来自于CPU外部，当CPU外部有需要处理的事情发生的时候，相关的芯片将向CPU发出相应的中断信息。CPU在执行了当前的指令后，可以检测到发送过来的中断信息，引发中断过程。

在CPU系统中，外中断源一共有以下两类

一. 可屏蔽中断

可屏蔽中断是CPU可以不响应的外中断。CPU是否响应，要看标志寄存器IF位的设置。如果IF = 1，CPU在执行完当前指令后会响应中断；如果IF = 0，则不响应可屏蔽中断。

回忆一下内中断的中断过程：

(1) 取中断状态码 n

(2) 标志寄存器入栈

(3) CS，IP入栈

(4) (IP) = (n * 4), (CS) = (n * 4 + 2)

可屏蔽中断引发的终端过程，除了第一步的实现有所不同外，基本上与内中断的过程相同。

当然，如果中断处理程序中需要处理可屏蔽中断时，则在执行完当前指令后，立即响应，引发中断过程，可以用指令将IF设置为1。8086CPU提供的设置IF指令如下：

sti，设置IF = 1；

cli，设置IF = 0。

二. 不可屏蔽中断

不可屏蔽中断是CPU必须响应的外中断。当CPU检测到不可屏蔽中断信息时，则在执行完当前指令后，离开响应，引发中断过程。

对于8086CPU，不可屏蔽中断的中断类型码固定为2，所以中断过程中，不需要取中断类型码，立即响应，引发中断过程：

(1) 标志寄存器入栈，IF = 0， TF = 0；

(2) CS， IP入栈；

(3) (IP) = (8)， (CS) = (0ah)

5.2 RAM 随机存储器

5.2.1 SRAM 静态 RAM

1. SRAM 的特点

SRAM = Static RAM，静态随机存储器特点：- 速度快- 状态稳定- 不需要刷新- 单元电路复杂- 集成度低- 功耗较大- 价格较高- 常用于高速缓存 Cache

PPT 中明确给出 SRAM“速度快，状态稳定”，但“位单元电路复杂、集成度低、功耗较大、价格偏高”，主要用于高速缓存。

2. 常见 SRAM 芯片

2114：1K × 46116：2K × 86232：4K × 86264：8K × 862256：32K × 864C512：64K × 8

这里的写法非常重要：
2K × 8 表示：- 有 2K 个存储单元- 每个存储单元 8 位- 总容量 = 2K × 8 bit = 2KB

考试里经常考：
芯片容量 = 单元数 × 每单元位数地址线根数 = log2(单元数)数据线根数 = 每单元位数

例如：
6116 = 2K × 82K = 2048 = 2^11所以地址线需要 11 根：A10 ~ A0每个单元 8 位所以数据线需要 8 根：I/O7 ~ I/O0

PPT 里 6116 的容量是 2K×8bit，即 2048 字节，并列出了地址线 A10～A0、数据线 I/O7～I/O0 等主要引脚。

5.2.2 DRAM 动态 RAM

1. DRAM 的特点

DRAM = Dynamic RAM，动态随机存储器特点：- 速度比 SRAM 慢- 用电容存储电荷- 状态不稳定- 必须定时刷新- 单元电路简单- 集成度高- 功耗小- 价格低- 常用于主存/内存条

PPT 中给出 DRAM 的典型刷新间隔为 2ms，并指出它主要用于构造内存条。

2. SRAM 和 DRAM 对比

对比项 SRAM DRAM
存储原理 触发器 电容
是否刷新 不需要 需要
速度 快 较慢
集成度 低 高
功耗 较大 较小
成本 高 低
典型用途 Cache 主存

记忆口诀：
S = Stable = 稳定，不刷新，贵且快D = Dynamic = 动态，要刷新，便宜容量大

5.2.3 DRAM 为什么要刷新？

DRAM 单元靠电容有没有电荷表示 0/1。问题是：电容会漏电。

所以 DRAM 不是写进去就永久稳定，而是要周期性把数据读出、放大、再写回去，这就叫刷新。

PPT 里 2164A 的刷新操作是：刷新时只接收行地址，选中若干行单元，把信息送到读出放大器放大后再写回原单元；刷新时 DRAM 不能被读写。

刷新方式：异步刷新

典型刷新间隔：2ms2164A 共 128 个刷新周期每隔：2ms / 128 = 15.6μs刷新一行。

PPT 中也给出异步刷新按 15.6μs 间隔依次刷新，并由专门 DRAM 控制器控制。

5.3 ROM 只读存储器

5.3.1 ROM 的核心特点

ROM = Read Only Memory特点：- 正常工作时主要读出- 掉电后内容不丢失- 常用于存放 BIOS、固定程序、表格、常量等

你可以把 RAM 和 ROM 这样区分：
RAM：运行时临时放数据，掉电丢失ROM：长期保存固定内容，掉电不丢

5.3.2 EPROM 27128

PPT 重点讲了 EPROM 27128。它的容量是：
27128 = 16K × 8

所以：
16K = 2^14地址线：14 根，A13 ~ A0数据线：8 根，D7 ~ D0

PPT 中 27128 内部包括存储阵列、X/Y 译码器、输出允许/片选/编程逻辑、数据输出缓冲器；其容量为 16K×8，A13～A0 共 14 根地址线，D7～D0 为 8 位数据线。

EPROM 的常见引脚理解

A13 ~ A0：地址线，用来选择芯片内部哪个单元D7 ~ D0：数据线，用来输出/编程输入数据CE：片选，决定这片芯片是否被选中OE：输出允许，读出时让数据出现在数据线上PGM：编程控制VPP：编程电压VCC/GND：电源和地

5.3.3 EEPROM 2817A

EEPROM = Electrically Erasable Programmable ROM特点：- 可电擦除- 可电写入- 编程前能自动擦除要写入的单元

PPT 中 EEPROM 2817A 容量为 2KB，存取时间 150ns，写入时间和擦除时间约 10ms。

5.4 存储器与 CPU 的连接

这部分是第5章最容易出大题的地方。
5.4.1 存储器接口设计要考虑什么？

存储器与CPU连接时，要考虑：1. 地址总线怎么连2. 数据总线怎么连3. 控制总线怎么连4. CPU负载能力是否够5. 存储器速度是否跟得上CPU时序6. 地址空间如何分配7. 片选信号如何产生

PPT 中明确说，要考虑 CPU 总线负载能力、CPU 时序与存储器存取速度配合、地址分配和片选、控制信号连接。

5.4.2 地址线：高位片选，低位片内寻址

这是本节的灵魂。
低位地址线：接到存储芯片的地址引脚，用来选择芯片内部哪个单元。高位地址线：送入译码器，用来产生片选信号，决定选中哪一片芯片。

PPT 中说，通常 CPU 地址信息的高位用来生成片选信号，低位直接连到芯片地址线上，实现片内寻址。

5.4.3 片选信号 CS/CE

CPU 地址空间很大，但一片芯片容量有限。

所以访问某个地址时，系统要先判断：
这个地址属于哪一片芯片？

选中芯片的信号就叫：
片选信号：CS 或 CE

常见片选信号是低电平有效：
CE = 0：芯片被选中CE = 1：芯片不工作

5.4.4 74LS138 译码器

74LS138 = 3-8译码器输入：C B A 三位二进制输出：Y0 ~ Y7 八个输出特点：某一时刻只有一个输出为低电平

PPT 中说 74LS138 输入 3 位二进制码，在 8 个输出中产生 1 个低电平片选信号。

可以这样记：
CBA = 000 -> Y0 = 0CBA = 001 -> Y1 = 0CBA = 010 -> Y2 = 0…CBA = 111 -> Y7 = 0

5.4.5 存储空间扩展

1. 位扩展

位扩展：增加每个存储单元的位数

比如 CPU 数据总线是 8 位，但芯片是：
64K × 1

一片只能提供 1 位数据，所以要 8 片并联：
8片 64K × 1 -> 64K × 8

PPT 中的例子就是用 8 片 64K×1 芯片扩展成 64KB 存储器，各片地址线并接，各 I/O 脚分别接 D7～D0。

2. 字扩展

字扩展：增加存储单元个数，也就是扩大地址范围

例如：
16K × 8 -> 64K × 8

一片是 16K，要变成 64K：
64K / 16K = 4所以需要 4 片。

PPT 中例 5.3 正是用 4 个 16K×8 芯片字扩展为 64K×8，并用 2-4 译码器产生片选信号。

3. 字位扩展

字位扩展 = 位数不够 + 字数不够

例如：
用 1K × 4 构成 4K × 8

步骤：
第一步：位扩展2片 1K×4 -> 1K×8第二步：字扩展4组 1K×8 -> 4K×8

PPT 例 5.4 正是用 1K×4 的 2114 构成 4K×8：先 2 片并成 1KB，再 4 组字扩展。

5.4.6 三种片选方法

1. 线选法

用某几根高位地址线直接作为片选信号。

优点：
电路简单

缺点：
很多高位地址没有参与译码会造成地址重叠地址空间浪费

PPT 中线选法使用某 1 位高位地址做片选，电路简单但空间浪费大，会导致地址重叠和地址不连续。

2. 全译码法

所有高位地址线都参与译码。

优点：
每个存储单元地址唯一不存在地址重叠

缺点：
译码电路复杂

PPT 中全译码法定义为全部高位地址参与译码，使每个存储单元地址唯一，不存在地址重叠，但译码电路复杂。

3. 部分译码法

只让一部分高位地址参与译码。

特点：
比全译码简单但仍可能产生地址重叠

PPT 中部分译码法只对高位地址中的某几位译码，未参与译码位可以是 0 或 1，因此每个存储单元可能对应多个地址。

6.1 I/O接口

6.1.1 为什么需要 I/O 接口？

CPU 和存储器比较“合拍”，但 CPU 和外设差异太大。
CPU：- 速度快- 电平标准统一- 数据格式规整- 时序严格外设：- 速度慢- 种类多- 电平可能不同- 数据格式可能不同- 工作时序不统一

所以中间要加：
I/O接口电路

PPT 中说，I/O 接口电路是外设与计算机之间传送信息的交接部件，每个外设都要通过接口电路才能与主机相连。

6.1.2 I/O接口的功能

1. 数据缓冲   解决CPU快、外设慢的问题。2. 电平转换   解决TTL、RS-232等电平不一致问题。3. 信息格式转换   例如模拟量/数字量转换，串行/并行转换。4. 时序控制   通过状态、应答、中断等信号协调CPU和外设。5. 地址译码   判断CPU当前访问的是哪个I/O端口。6. 提供读/写、中断等控制逻辑

6.1.3 I/O端口

CPU 和外设交换的信息主要有三类：
1. 数据信息2. 状态信息3. 控制信息

所以端口也分三类：

端口类型 作用
数据端口 存放输入/输出数据
状态端口 让 CPU 读取外设状态
控制/命令端口 CPU 向接口发命令

PPT 中把 I/O 端口定义为接口电路中相关寄存器及控制逻辑，CPU 可直接读写端口信息。

6.1.4 常见状态位

Ready：准备好。输入时表示有数据等CPU读；输出时表示输出缓冲器空，可以接收新数据。Busy：忙。表示外设正在工作，暂时不能接收新数据。Error：错误。表示传送过程中发生错误。

6.1.5 I/O端口寻址方式

1. 存储器映像寻址

I/O端口和内存统一编址。

特点：
优点：访存指令都能访问I/O端口缺点：占用内存地址空间

2. I/O单独编址

I/O端口单独拥有地址空间。CPU用专门的 IN / OUT 指令访问。

PPT 中说 8086 系统采用 I/O 单独编址方式。

6.1.6 CPU与外设的数据传送方式

1. 程序控制方式

又分两种：
无条件传送：默认外设随时准备好，直接 IN/OUT。条件传送 / 查询方式：CPU先读状态口，确认Ready/Busy，再传送数据。

PPT 中说明程序控制方式由程序完成，分为无条件传送和条件传送；条件传送要先读取状态口，反复检测外设是否准备好。

2. 中断方式

CPU平时做自己的事。外设准备好后发中断请求。CPU响应中断，执行中断服务程序完成一次数据传送。

PPT 中提到查询方式会让 CPU 大量等待，而中断方式下 CPU 平时执行主程序，外设准备好后再请求 CPU 服务。

3. DMA方式

DMA = Direct Memory Access直接存储器存取

特点：
CPU让出总线控制权DMA控制器接管地址总线、数据总线、控制总线外设和内存直接批量传送数据传完后归还总线

PPT 中 DMA 控制器可以给出内存地址、修改地址指针、设定传送字节数，并向内存和外设发读写控制信号。

6.2 8255A 工作原理

6.2.1 8255A是什么？

8255A = 可编程并行I/O接口芯片PPI = Programmable Peripheral Interface

它可以通过编程工作在三种方式：
方式0：基本输入输出方式1：选通输入输出方式2：双向总线方式

PPT 中明确 8255A 是通用可编程并行 I/O 接口芯片，可通过编程工作于 3 种数据传输方式。

6.2.2 8255A内部结构

8255A内部主要包括：1. 数据端口A、B、C2. A组和B组控制逻辑3. 数据总线缓冲器4. 读/写控制逻辑

PPT 中给出 8255A 有端口 A/B/C，其中 C 口可分成上半部和下半部，还有 A组/B组控制逻辑、数据总线缓冲器、读写控制逻辑。

6.2.3 三个端口

A口：8位，PA7 ~ PA0B口：8位，PB7 ~ PB0C口：8位，PC7 ~ PC0

C口特殊：
C口可以拆成：- C高：PC7 ~ PC4- C低：PC3 ~ PC0C口还常用作A口、B口的联络/状态控制信号。

6.2.4 A组和B组

A组：- 管理A口- 管理C口高4位 PC7 ~ PC4B组：- 管理B口- 管理C口低4位 PC3 ~ PC0

这点很重要，因为控制字里会分别设置 A组、B组。

6.2.5 端口地址选择

8255A 用 A1A0 选择内部端口：

A1A0 选择
00 A口
01 B口
10 C口
11 控制口

PPT 中给出：若 8255A 基地址为 60H，则 A口、B口、C口、控制口分别为 60H、61H、62H、63H。

在 8086 的 16 位系统中，如果 8255A 的 D7～D0 接低 8 位数据总线，则通常用偶地址访问。例如基地址 F0H 时，A/B/C/控制口分别是 F0H、F2H、F4H、F6H。

6.2.6 8255A工作方式

方式0：基本输入输出

适合简单I/O不需要应答信号A口、B口可作8位输入/输出C高、C低可作4位输入/输出输出可锁存输入一般不锁存

PPT 中说方式0适用于不需要应答信号的简单 I/O，A口、B口作8位端口，C高和C低作两个4位端口或合成8位端口。

方式1：选通输入/输出

适合需要握手信号的I/OA口、B口作为数据口C口部分引脚作为联络信号支持中断请求

PPT 中方式1又称选通输入/输出方式，A口、B口作数据口，PC2～PC0、PC5～PC3 用作联络信号。

典型联络信号：
STB：选通信号IBF：输入缓冲器满OBF：输出缓冲器满ACK：外设应答INTR：中断请求INTE：中断允许

方式2：双向总线方式

只有A口支持方式2A口可双向传送数据输入、输出都可锁存C口提供联络信号

PPT 中说方式2也称双向总线方式，只有 A口支持，A口既能输入也能输出。

6.3 8255A应用举例

6.3.1 例1：开关状态检测 + LED显示

题意：
8个开关 K7 ~ K08个LED LED7 ~ LED0要求：开关断开 -> 对应LED亮开关闭合 -> 对应LED灭

硬件思路：
A口输入：接开关B口输出：接LEDC口不用

PPT 中例1就是 A口输入接 K7～K0，B口输出接 LED7～LED0，端口地址为 F0H、F2H、F4H、F6H，分别对应 A口、B口、C口、控制口。

控制字：
A口方式0输入B口方式0输出C口不用控制字 = 10010000B = 90H

程序逻辑：
MOV DX, 0F6HMOV AL, 10010000BOUT DX, ALTEST_IT: MOV DX, 0F0H IN AL, DX MOV DX, 0F2H OUT DX, AL CALL DELAY JMP TEST_IT

核心不是背程序，而是看懂：
初始化8255A -> 从A口读开关 -> 向B口输出 -> LED显示 -> 循环

6.3.2 例2：开关状态用七段LED显示

题意：
A口接4个开关 K3 ~ K0B口接七段LED显示器4位开关共有16种状态，显示0~F

PPT 中 A口方式0输入，B口方式0输出；PB0～PB6 接 a～g 段，通过 74LS04 反相驱动。

七段码表：
TABLE DB 40H,79H,24H,30H,19H,12H,02H,78H DB 00H,18H,80H,03H,43H,21H,06H,0EH

程序核心：
IN AL, 60H ; 读A口AND AL, 0FH ; 只取低4位MOV BX, OFFSET TABLEXLAT ; 查表OUT 61H, AL ; 输出七段码

这里最关键的是：
开关状态不是直接输出到七段LED。而是：开关状态 -> 作为表下标 -> 查七段码 -> 输出到B口

一句人话：A口负责“看”，B口负责“说”。

  1. 为什么控制字是 10010000B？

8255A 上电后不知道 A口、B口该输入还是输出，所以 CPU 要先写一个控制字告诉它：
A口：方式0输入B口：方式0输出C口：不用

控制字：
MOV AL, 10010000BOUT 0F6H, AL

拆开看：
10010000BD7 = 1：这是“方式选择控制字”D6D5 = 00：A组方式0D4 = 1：A口输入D3 = 0：C口高4位输出/不用D2 = 0：B组方式0D1 = 0：B口输出D0 = 0：C口低4位输出/不用

所以它的含义就是：
把8255A设置成：A口输入，B口输出，方式0。

PPT 中也写了：A口方式0输入，B口方式0输出，C口未用，控制字为 10010000。

  1. 端口地址为什么是 F0H、F2H、F6H？

PPT 给出本例中 8255A 的 4 个端口地址：

端口 地址
A口 F0H
B口 F2H
C口 F4H
控制口 F6H

也就是说：
0F0H -> A口0F2H -> B口0F6H -> 控制口

所以程序里：
MOV DX, 0F6HOUT DX, AL

意思是：
把控制字写入控制口，初始化8255A。

然后：
MOV DX, 0F0HIN AL, DX

意思是：
从A口读开关状态到AL。

再然后：
MOV DX, 0F2HOUT DX, AL

意思是：
把AL里的开关状态输出到B口，让LED显示。

PPT 程序也正是这个流程：先向 F6H 写控制字，再从 F0H 读 A口，最后向 F2H 写 B口。

  1. 最关键的一点：为什么读进来能直接输出？

因为这个硬件刚好满足：
开关断开 -> A口读到 1开关闭合 -> A口读到 0B口输出 1 -> LED亮B口输出 0 -> LED灭

题目要求是：
开关断开 -> LED亮开关闭合 -> LED灭

完全对应上了！

所以不需要取反，不需要判断，直接：
IN AL, DX ; 读开关OUT DX, AL ; 输出给LED

就行。

举个例子：
假设 8 个开关状态读入后：AL = 10110010B

那么输出到 B口后：
PB7~PB0 = 10110010B

于是：
值为1的那些LED亮值为0的那些LED灭

也就是 LED 状态和开关断开/闭合状态一一对应。
